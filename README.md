# WorkBuddy · 个人工作台（PWA 手机 App）

一个可以「添加到小米15桌面、像原生 App 一样全屏使用」的个人工作台：
**每日打卡 / 学习番茄钟 / 英文晨读跟读 / 每日 30 词 / 三类每日热点 / 妆容穿搭 / 体重与运动 / 记账周报月报 / 工作复盘**，
所有智能内容由 **火山方舟 · 豆包大模型** 每日自动生成，数据全部保存在手机本地，几乎免维护。

> 主题：柔和蓝渐变 + 渐变按钮 + 右上角一键深色模式。

---

## 一、3 分钟跑起来（本地预览）

```bash
cd workbuddy
python3 -m http.server 8899
# 电脑浏览器打开 http://127.0.0.1:8899
# 手机和电脑连同一个 WiFi，用手机浏览器打开 http://<电脑局域网IP>:8899
```

> ⚠️ 必须用 http(s) 打开，不能直接双击 index.html（file:// 下 Service Worker 与联网功能不可用）。

## 二、安装到小米15 桌面（变成 App）

1. 用 **小米浏览器**（或 Chrome）打开应用网址（见下方部署方案，推荐 https）；
2. 点底部菜单 **⋮ → 添加到桌面 / 安装应用**；
3. 桌面会出现「工作台」图标，点开即**全屏独立运行**（无浏览器地址栏），支持离线打开。

## 三、配置火山方舟豆包 AI（必做，否则只有示例内容）

1. 登录 [火山方舟控制台](https://console.volcengine.com/ark)；
2. 「API Key 管理」创建一个 Key；
3. 「在线推理 / 模型广场」开通豆包模型：
   - **文本模型**（短文/单词/热点用）：推荐便宜快的 `doubao-seed-1-6-flash` 系列，模型 ID 形如 `doubao-seed-1-6-flash-250715`；
   - **视觉模型**（账单截图识别用，需支持图片）：如 `doubao-seed-1-6-250615`；
4. 打开 App → **设置** → 粘贴 API Key 与两个模型 ID → **保存并测试连接**；
   - **API 地址（Base URL）**：默认已填 Code Plan（coding 套餐）地址 `https://ark.cn-beijing.volces.com/api/coding/v3`；若你用的是普通按量付费 Key，请改为 `https://ark.cn-beijing.volces.com/api/v3`；
5. 看到「🎉 豆包 AI 连接成功」即可。此后每天首次打开，英文短文、中文金句、30 个单词、三类热点、妆容穿搭会**自动生成并缓存**，当天重复查看不重复消耗。

> Key 只保存在你手机的浏览器 localStorage 中，随数据导出备份，不会经过任何第三方服务器（浏览器直连火山方舟）。

## 四、部署到公网（手机随时用，三选一）

- **GitHub Pages（免费）**：新建仓库 → 上传本目录 → Settings → Pages → 选 main 分支 → 得到 `https://<用户名>.github.io/<仓库名>/`，https 自带，安装体验最佳。
- **火山引擎静态网站 / 对象存储 TOS**：控制台开启静态网站托管，上传全部文件即可（你已有火山云账号，最顺手）。
- **局域网自用**：电脑上常开 `python3 -m http.server 80`，手机连家里 WiFi 访问（出门不可用）。

### 📷 账单截图 AI 识别批量导入（新）

在「记账」页点 **选择截图识别**，上传**支付宝 / 微信 / 美团 / 银行账单截图**：

1. 豆包**视觉大模型**逐条识别每笔交易的金额、收支类型、分类、商户、来源；
2. 弹出预览：顶部显示**总笔数 / 支出合计 / 收入合计**，并按**分类小计**（如 🍜餐饮 ¥23、🚌交通 ¥6）；
3. 每笔可**勾选/取消**（识别错的勾掉即可），确认后一键批量导入；
4. 导入的账单带「截图识别」来源标签，自动计入本月概览与周/月图表。

> 需要在「设置」里额外配置一个**支持图片的视觉模型 ID**（默认 `doubao-seed-1-6-250615`，在方舟控制台开通即可）。截图越清晰、单笔记录越完整，识别越准；建议一次截一屏账单。
| 📝 工作复盘 | 严格按你的模板：今日要事（完成度%/干扰源）、Keep/Improve/根本原因、一句话洞见、情绪标签+原因、明日铁三角；**AI 教练一键点评润色**；历史记录可回溯 |
| ⚙️ 设置 | API 配置、数据 JSON 导出/导入备份、清除今日 AI 缓存重新生成 |

顶部 **⟳** 按钮：强制重新生成当天全部 AI 内容。

## 六、两个已做的产品替代方案（请知悉）

1. **支付宝/微信/美团账单自动同步**、**小米体脂秤自动同步**：三者均无面向个人开发者的开放接口，无法合法自动抓取。本应用采用「付款后 3 秒速记 + 体重随手录 + 周月图表复盘」的零成本方案；数据支持导出，随时可迁移。
2. **定时后台推送**：网页应用在关闭状态下无法常驻后台。采用「**每天打开 App 自动拉取当日内容** + 打开期间番茄钟蜂鸣提醒 + Service Worker 离线缓存」，自用场景下打开即刷新，体验等同于每日更新。

## 八、常见问题

- **跟读打分没反应？** 用 Chrome/小米浏览器最新版，并允许麦克风权限；iOS 不支持网页语音识别。
- **发音是机械音？** Android 系统自带 Google TTS 时音质最好，可在系统「语言与输入法 → 文字转语音」切换引擎。
- **换手机？** 设置 → 导出 JSON，新机导入即可。
- **内容想换口味？** 顶部 ⟳ 重新生成；所有提示词在 `js/ai.js` 中，可自行调整难度、风格。
